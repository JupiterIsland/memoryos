KEY FORMULAS (Remember These)
=============================

Safe VRAM Usage:
  available_vram = total - reserved - overhead - safety_margin
  safe_threshold = available_vram * 0.75
  
  Example: 24GB GPU → 18.2GB available → 13.6GB safe
           Models > 13.6GB → Recommend optimization

Quantization Impact:
  FP32 (100%) → FP16 (50%) → Q8 (25%) → Q4 (12.5%) → Q2 (6%)
  
  Example: Llama 65B
    FP16: 130GB (doesn't fit)
    Q4: 33GB (fits RTX 4090 with CPU offload)

ROI Calculation:
  breakeven_days = gpu_cost / daily_value
  daily_value = hours_saved_per_day * engineering_rate
  
  Example: $4800 GPU, saves 1.5 hrs/day at $200/hr
    daily_value = 1.5 * 200 = $300
    breakeven = 4800 / 300 = 16 days

Context Extension:
  hybrid_kv_gb = gpu_kv_available + cpu_kv_available
  extended_context = hybrid_kv_gb / bytes_per_token
  
  Example: 2GB GPU KV + 12GB CPU KV = 14GB total
    at 256KB per token = 56,000 tokens possible (56k context!)

ANTI-HYPE RULES (Critical)
===========================

Rule 1: "10x speedup" claim
  Reality: GPU cores limit to ~3x speedup for memory workloads
  Action: Flag as unrealistic

Rule 2: "No quality loss with quantization"
  Reality: Q4 loses 3-8%, Q2 loses 8-15%
  Action: Show realistic quality/speed tradeoffs

Rule 3: "Unlimited context length"
  Reality: Context * batch_size * hidden_dim must fit in VRAM
  Action: Show actual context limits

Rule 4: "Always upgrade to newest GPU"
  Reality: Previous-gen GPU has 70% cost, 90% performance
  Action: Compare current vs previous gen ROI

Rule 5: "This GPU is future-proof for 5 years"
  Reality: Models grow 3-4x every 1.5 years
  Action: Show realistic 2-3 year lifespan
