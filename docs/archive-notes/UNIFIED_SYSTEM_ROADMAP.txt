UNIFIED DATA FLOW
=================

User runs inference:
  Apex-Metal.run_inference()
       ↓
  [Capture metrics]
  time_to_first_token, throughput, GPU state, quality
       ↓
  [Log automatically via InferenceLogger]
  → memoryos.inference_log table
  → MemoryOS temporal graph
       ↓
  [Return result to user]
       ↓
  User continues work


Daily (2 AM):
  QuietAdvisorScheduler wakes up
       ↓
  [Get all inferences from yesterday]
  FROM memoryos.inference_log WHERE timestamp = yesterday
       ↓
  [Run 10 detector algorithms in parallel]
  1. Context waste
  2. Model thrashing
  3. Performance envelope
  4. Repeated failures
  5. Quality drift
  6. Efficiency frontier
  7. Thermal throttling
  8. Default suboptimality
  9. Recency bias
  10. Anomaly detection
       ↓
  [Rank by: time_savings + quality + novelty + user_preferences]
       ↓
  [Select top 1 insight]
       ↓
  [Store in quiet_advisor.cards]
       ↓
  Done in <5 minutes


Next morning:
  User opens Jupiter One
       ↓
  [Jupiter One dashboard loads]
       ↓
  CardDisplayService.get_card_for_user()
       ↓
  [Show today's insight card]
       ↓
  User sees: "PATTERN DETECTED: Context Waste (74%)"
       ↓
  User can:
    [Try reduced context] → Apex-Metal config update → Next inference faster
    [Learn more] → Deep dive explanation
    [Dismiss] → Card fades, preference updated
    [Archive] → Never show this type again

RISK FACTORS & MITIGATIONS
===========================

Risk 1: Jupiter One Hardware Reality takes longer than 8 weeks
  Mitigation: Can launch Quiet Advisor separately (8 weeks)
             Advisor works on any GPU, provides value independently

Risk 2: Users don't engage with Advisor cards
  Mitigation: Card quality critical - invest in UX/copy
             A/B test card messaging
             Fallback: Show generic helpful tips first month

Risk 3: Privacy concerns about inference logging
  Mitigation: All data stored locally by default
             Opt-in for cloud analytics
             GDPR compliant from day 1
             User can delete history anytime

Risk 4: Competitor launches similar feature
  Mitigation: Already designed and ready to ship (8 weeks)
             First-mover advantage in virality
             Subtle, elegant design hard to copy quickly

Risk 5: Detection algorithms produce wrong recommendations
  Mitigation: All detector output verified by humans first
             Conservative confidence thresholds
             Granite validation layer catches false claims
             User override always available
