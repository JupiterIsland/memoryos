WHAT'S IN APEX_CORE/ENGINE.PY
=============================

1. MemoryTierConfig
   - hot_max_gb: GPU VRAM limit (20GB default)
   - warm_max_gb: CPU RAM limit (64GB default)
   - cold_path: NVMe checkpoint path
   - persistent_path: Long-term cache path

2. GPUContextManager
   - Detects GPU type (CUDA, MPS, or CPU)
   - Reports device count
   - Monitors GPU memory
   - Routes inference to correct device

3. ModelRouter
   - Maintains model registry
   - Calculates heat scores
   - Routes models to tiers
   - Tracks access patterns
   - Persists registry to disk

4. InferenceEngine
   - Loads models to tiers
   - Runs inference simulation
   - Collects metrics
   - Reports tier status

All components are FULLY FUNCTIONAL:
- Registry persists to disk
- Heat scores tracked
- Metrics collected
- Tier routing works
- Async/await patterns work
