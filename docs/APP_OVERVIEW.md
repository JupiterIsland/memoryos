# Apps Overview

This repository contains experimental applications built on top of MemoryOS and the Jupiter One engine. The main apps are stored under the `apps/` directory.

Included apps:

- apps/jupiter-tv/ — Desktop demo: Live AI Commentary (DeepSeek‑V3)
- apps/jupiter-tv-mobile/ — Kivy Fire TV app + M3U parser + DuckDB MemoryOS
