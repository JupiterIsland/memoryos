MemoryOS // Jupiter Studio v1.0.0-RC1

MemoryOS — AI Workstation

MemoryOS is a desktop AI workstation that brings multiple models, project context, and live hardware telemetry into a single interface.

Instead of switching between AI tools, Jupiter Studio lets you compare models side-by-side, attach repository files, route tasks automatically, and keep local GPU VRAM free.

Download v1.0.0-RC1 GitHub Repository User Guide

Key Features

  • Multi-model AI workstation (Quantum, Radeon & Atari B&W themes)
  • Smart model routing (d3 Auto-Route + 5.37 μs Speculative MLP)
  • Dual Arena side-by-side model comparison
  • Repository-aware conversations & secret-file upload guard
  • AMD Token Lab, Ollama, NVIDIA NIM, Hugging Face & DGX Spark support
  • Real-time hardware telemetry & Workstation Health Score
  • One-click Copilot bundle export
  • Standalone Windows, macOS & Linux builds

Quick Start

  1. Download the latest release (v1.0.0-rc1)
  2. Launch Jupiter Studio
  3. Select a model (or keep Auto-Route)
  4. Attach project files or screenshots
  5. Start working — 0 MB local studio VRAM
