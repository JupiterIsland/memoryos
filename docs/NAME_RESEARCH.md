## Required Manual Checks Before Renaming

Before renaming the GitHub repo or recording permanent branding:
1. Verify directly in browser/API: `https://github.com/search?q=<name>&type=repositories`, `https://pypi.org/project/<name>/`, and `https://www.npmjs.com/package/<name>`.
2. Search trademarks in Class 9 / Class 42:
   - **UK IPO:** `https://www.gov.uk/search-for-trademark`
   - **USPTO:** `https://tmsearch.uspto.gov/`
   - **EUIPO:** `https://euipo.europa.eu/eSearch/`
3. Check `.com` / `.dev` domain availability if hosting project docs outside GitHub Pages.
