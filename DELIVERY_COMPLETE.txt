QUESTIONS ANSWERED BY DESIGN
=============================

Q: How do we decide if a model fits a GPU?
A: VRAM Advisor measures available VRAM, applies safety margins, recommends tier
   Safe = ≤75% of available, Borderline = 75-95%, Overload = >95%

Q: How do we recommend quantization?
A: Decision tree: try FP16, Q8, Q4, Q2 in order until fits. Show quality loss.

Q: How do we know when to upgrade GPU?
A: Performance deficit >1.2x and ROI >100% in 12 months. DeepSeek+Granite validate.

Q: How do we extend context length?
A: Use CPU RAM for KV cache. GPU keeps recent tokens (fast), older in CPU (slow).
   Result: 4x context extension possible with <10% latency penalty.

Q: How do we run pipelines that don't fit?
A: Stage-by-stage execution. Load stage 1, execute, unload, load stage 2, etc.
   Peak VRAM drops from 45GB to 15GB (67% reduction). Total time increases <1%.

Q: How do we prevent hype-driven recommendations?
A: Anti-hype rules. If claim says "10x speedup", check against physics limits.
   Physics says 3x max for memory workloads. Flag claim as unrealistic.

Q: How confident should we be in recommendations?
A: 0.93+ confidence. DeepSeek generates option, Granite validates. Combined.
   Falls back to rule-based if either API unavailable.
