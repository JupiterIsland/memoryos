INTEGRATION WITH MEMORYOS
==========================

Tier Routing:
  Models automatically placed in optimal tier
  Based on MemoryOS heat score calculations
  Automatic migration as access patterns change

Temporal Graph:
  Model state stored in temporal graph
  Access history tracked for analytics
  Relationships mapped for prefetching

Checkpoint Management:
  Checkpoints stored in NVMe tier
  Rapid recovery from tier 3
  Cross-session state preservation

Performance Metrics:
  Integrated with MemoryOS metrics collection
  Heat score updates on each access
  Tier migration decisions logged


QUICK START GUIDE
=================

1. Install Dependencies:
   pip install -r requirements-apex.txt

2. Start Service:
   docker compose -f docker-compose.apex.yml up

3. Load Model:
   curl -X POST http://localhost:8000/models/load \
     -H "Content-Type: application/json" \
     -d '{"model_id": "mistral-7b", "tier": "hot"}'

4. Run Inference:
   curl -X POST http://localhost:8000/inference \
     -H "Content-Type: application/json" \
     -d '{
       "model_id": "mistral-7b",
       "prompt": "Hello",
       "max_tokens": 256
     }'

5. Check Health:
   curl http://localhost:8000/health

CONFIGURATION REFERENCE
=======================

Environment Variables:
  CUDA_VISIBLE_DEVICES          - GPU device IDs
  MEMORYOS_TLB_CACHE           - Hot cache path
  MEMORYOS_TEMP_GRAPH          - Temporal graph path
  MEMORYOS_CHECKPOINT_DIR      - NVMe checkpoint path

Python Settings:
  MemoryTierConfig.hot_max_gb   - GPU VRAM limit (20GB)
  MemoryTierConfig.warm_max_gb  - CPU RAM limit (64GB)
  MemoryTierConfig.cold_path    - NVMe path
  MemoryTierConfig.persistent_path - Cache path


TROUBLESHOOTING
===============

GPU Not Detected:
  - Check nvidia-smi
  - Set CUDA_VISIBLE_DEVICES
  - Verify Docker --gpus flag

Out of Memory:
  - Reduce hot_max_gb
  - Use quantization
  - Increase warm_max_gb

Slow Inference:
  - Check /metrics endpoint
  - Monitor GPU utilization
  - Review tier migrations
