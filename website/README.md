# Website files

Keep the website's source files in this `website/` folder in the GitHub repository.

## Where to work

On your laptop, place the repository wherever you like (for example, `Documents/memoryos/`) and edit the files inside `website/`. Commit and push your changes to GitHub so the online repository stays in sync. Google Drive is optional for backups or sharing drafts; it does not automatically publish or sync this GitHub folder unless you set up a separate sync.

## Folder guide

- `pages/` — website page files and page content.
- `assets/` — images, logos, stylesheets, fonts, and other static files.

Add files to these folders as the website is built. Keep passwords, API keys, and other private information out of GitHub.

The project’s website framework and publishing setup have not been identified yet, so filenames and subfolders can be adjusted to match them.
