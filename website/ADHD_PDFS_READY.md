### Topaz Infographic (Keep Handy)

**Designed for:**
- Decision-tree for video type
- Column 1: "Is it modern phone? NO TOPAZ"
- Column 2: "1990s VHS? Use 2-stage Iris→Proteus"
- Column 3: "1080p→4K? Use Proteus native 2x, NOT Rhea"

**Hardware Traps Highlighted:**
- Rhea @ 2x = renders at 8K then downscales (DON'T DO THIS)
- Phone footage = already denoised by ISP chip (DON'T DOUBLE-PROCESS)
- CPU Grain = CPU bottleneck (use prenoise instead)

**Use it for:**
- Before opening Topaz (print beside monitor)
- Deciding which preset to use
- CLI reference (copy-paste parameters)
