🛠️ The Core Tools Explained

Four pillars of modern development. Learn one at a time.

The Big Picture: These four tools are the backbone of modern development. Bash is your control center. Git tracks your work. Curl lets you talk to services. Pip installs Python libraries. Together, they're how 99% of developers get stuff done.

🖥️ Bash

Your direct line to the operating system. Instead of clicking buttons, you type commands. It's faster, scriptable, and it's what real developers use.

What It Is

A text-based interface (shell) that runs on every computer—Mac, Linux, Windows (with WSL).

What You Use It For

Navigate folders, run programs, automate tasks, manage files, run other tools.

$ cd projects
$ python script.py
$ pip install requests

🔗 Curl

The mailman of the internet. It sends requests to web servers and APIs, and brings back the response. It's how your code talks to external services.

What It Is

A command-line tool for making HTTP requests (GET, POST, etc.) to URLs.

What You Use It For

Test APIs without a browser, download files, send data to services, check if a server is alive.

$ curl https://api.example.com/data
$ curl -X POST -d "name=Alice" https://api.example.com/users

📦 Pip

Python's app store. It downloads and installs Python libraries (packages) so you don't build everything from scratch.

What It Is

A package manager for Python. Think of it as a vending machine where you ask for libraries by name.

What You Use It For

Install libraries (requests, numpy, django, etc.), manage dependencies for your project.

$ pip install requests
$ pip install numpy pandas

📂 Git

The time machine for your code. Every change you make is tracked. You can see what changed, who changed it, and revert if something breaks.

What It Is

A version control system. It records the history of your project and lets multiple people work on the same code.

What You Use It For

Save code snapshots (commits), work with teams, switch between versions, backup your work to GitHub/GitLab.

$ git add .
$ git commit -m "Fixed login bug"
$ git push origin main
