## 📚 EDUCATION AS CORE VALUE

The Topaz presets aren't "monetization."  
They're **teaching.**

```
"Here's how 1990s VHS gets restored (and why)

Stage 1: Clean at native resolution (Iris LQ)
- Removes head-switching noise
- Strips tape degradation
- Preserves what's real

Stage 2: Upscale 2x (Proteus v4)
- Rebuilds resolution
- Adds film grain (not plastic)
- Respects original

This is archival science.
Learn it. Use it. Share it.
Become a restorer yourself."
```

**You're not selling presets. You're teaching craft.**
