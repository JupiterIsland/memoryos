## 🚀 How To Use It

### Option 1: Open in Browser
```bash
# Just double-click index.html in Windows Explorer
# It opens in your default browser
# Works offline (no internet needed)
```

### Option 2: Deploy on GitHub Pages
```bash
# Push to GitHub
git add index.html
git commit -m "Add landing page"
git push origin main

# Then go to repo Settings → Pages → Deploy from main
# Your site lives at: https://YOUR-USERNAME.github.io/rjmedia-liner-notes/
```

### Option 3: Serve Locally (for testing)
```bash
# Python 3
python -m http.server 8000
```
